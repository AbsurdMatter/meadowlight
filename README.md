# 🐝 Meadowlight

A cozy, educational voxel bee-farm builder. Plant flowers freely, watch the
meadow come alive with pollinators, and learn real bee ecology along the way —
at your own pace, with no way to lose.

Inspired by the freeform, no-pressure building of cozy city builders like
*Town to City*, Meadowlight swaps efficiency for ecology: the meadow's beauty
and biodiversity are the only progress bar.

## Status

Prototype in active development. See `ROADMAP.md` for the session plan.

## Stack

Vite · TypeScript · React · three.js (@react-three/fiber) · no backend

## Getting started

```bash
npm install
npm run dev
```

## Principles

1. Cozy, not efficient — no fail state, no timers, no scolding.
2. Freeform placement — no grid snap; organic layouts are celebrated.
3. Ecology is the mechanic — real pollinator principles drive everything.
4. Learning is diegetic — facts surface through observation, not quizzes.
5. Beauty is the progress bar — the scene itself is the feedback.
